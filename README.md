# GitHub User Finder

**Автор:** Габитова Азалия


## Описание

GitHub User Finder — это графическое приложение для поиска пользователей GitHub с возможностью сохранения избранных профилей. Приложение использует официальное GitHub API для получения информации о пользователях и сохраняет избранных в локальный JSON-файл.

## Функциональность

- ✅ Поиск пользователей GitHub по логину
- ✅ Отображение информации о пользователе (имя, локация, дата регистрации, репозитории, подписчики)
- ✅ Добавление пользователей в избранное
- ✅ Удаление из избранного
- ✅ Сохранение избранных в JSON-файл
- ✅ Просмотр детальной информации по двойному клику/выбору
- ✅ Валидация ввода (поле поиска не может быть пустым)

## Как использовать GitHub API

Приложение использует **GitHub REST API v3**. Основные эндпоинты:

### Поиск пользователя

```bash
GET https://api.github.com/users/{username}
```

**Пример ответа API:**
```json
{
  "login": "octocat",
  "name": "The Octocat",
  "location": "San Francisco",
  "public_repos": 8,
  "followers": 1234,
  "created_at": "2011-01-25T18:44:36Z",
  "html_url": "https://github.com/octocat"
}
```

##Обработка ошибок

**404** — пользователь не найден

**403** — превышен лимит запросов (60 запросов в час для неавторизованных)

**500** — ошибка на стороне GitHub

## Лимиты

Без аутентификации: 60 запросов в час

С аутентификацией: 5000 запросов в час
